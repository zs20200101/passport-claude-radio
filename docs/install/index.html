GitHub 下载超时时，使用官方备用接口

在电脑 PowerShell 运行以下命令，将安装包保存到当前目录：

Invoke-WebRequest -Headers @{Accept="application/octet-stream"} `
  -Uri "https://api.github.com/repos/zs20200101/passport-claude-radio/releases/assets/647030397" `
  -OutFile "Passport-Claude-Radio-v1.0.0.zip"

安装包 SHA256：0facad869907993021bee561b1b0f6443816c245ca7f149f9fe7a3aa70d2e4b6。备用入口同样由 GitHub 提供，无需登录。

首次安装完整镜像可能重置 Wi-Fi 和配对设置。每位使用者需要自己的 Passport、USB 数据线和电脑；设备使用 2.4 GHz Wi-Fi。安装包没有预置密码或密钥。

1 · 烧录 Passport

  1. 下载并解压安装包。用 USB 数据线连接设备，关闭占用串口的软件。
  2. 在电脑 Chrome／Edge 中打开网页烧录工具并授权串口，选择 firmware/FoloToy-AI-Passport-full.bin，从 0x0 写入。该工具由 Passport 官网提供。
  3. 重启设备。用手机连接设备的 LEO Radio 热点，打开 http://192.168.4.1，选择与电脑同一局域网的 2.4 GHz Wi-Fi，输入自己的密码。

2 · 运行电脑端

安装 Python 3.10 或以上，在解压目录打开 PowerShell：

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r tools/claude_lan_bridge/requirements.txt
.\.venv\Scripts\python.exe tools/claude_lan_bridge/setup.py
.\.venv\Scripts\python.exe tools/claude_lan_bridge/bridge.py --config "$env:LOCALAPPDATA\PassportClaude\config.json"

凤凰资讯还需要单独安装带 libmp3lame 的 FFmpeg，并确认桥接进程的 PATH 能找到 ffmpeg。桥接需持续运行。天气根据电脑的网络出口定位，VPN 可能影响城市。

3 · USB 配对与可选批准功能

另开 PowerShell，把示例 COM5 和 192.168.1.10 换成自己的设备串口、电脑局域网 IPv4：

.\.venv\Scripts\python.exe tools/claude_lan_bridge/setup.py --serial COM5 --host 192.168.1.10

设备显示“Claude 已连接”后可拔 USB 无线使用。建议路由器固定电脑 IP；防火墙如阻止 TCP 8765，仅放行可信私有局域网。先确认配对正常，再选择启用：

.\.venv\Scripts\python.exe tools/claude_lan_bridge/setup.py --install-hook

重启 Claude Code 会话。仅能控制触发 PermissionRequest hook 的 Code 会话，普通聊天和 Windows 弹窗不适用。真实 Claude Desktop hook 分发仍需使用者实测。移除对应 Passport hook 可恢复原权限流程。

按键

主页：单击上／下调音量，双击上／下换台，确定播放／暂停，长按确定进设置。权限提示：单击上批准、下拒绝。

升级与验证

已有本项目、分区一致时，可只将 firmware/FoloToy-AI-Passport.bin 写到 0x10000 保留兼容配置，切勿写到 0x0。完整镜像 SHA256：

71ac40b4a0f10beed7560d90a8c12287d22e14fed459f5d726ce5ec28a48a1ee

这份固件与已验收设备版本一致。已验证主页按键、显示、凤凰声音与模拟权限打断恢复；尚未验证所有电台和长期稳定性。网络和音源中断仍可能造成停播。权限 HTTP 有签名但不加密，仅用于可信局域网。
